# Veri Madenciliği Vize Rehberi

BSM 429 Veri Madenciliği dersinin 1–7. haftaları için özetler, formüller, elle çözülmüş örnekler, etkileşimli araçlar ve 10 vize denemesi (220 soru). Deneme 6–10 hocanın son duyurusuna göre hazırlandı: 20 soru, 7. hafta dahil, hesap makinesiz, yorum ağırlıklı.

Site: https://sametalici.github.io/veri-madenciligi-vize/

```bash
cd site
npm install
npm run dev
```

`node scripts/check.ts` Hafta 7 hesaplarını, soru yapısını ve tekrar eden soruları doğrular. `main` dalına gönderilen her değişiklik GitHub Pages'e otomatik yayınlanır.
