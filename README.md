# Veri Madenciliği Vize Rehberi

BSM 429 Veri Madenciliği dersinin 1–7. haftaları için özetler, formüller, elle çözülmüş örnekler, etkileşimli araçlar ve 11 vize denemesi (252 soru).

Site: https://sametalici.github.io/veri-madenciligi-vize/

```bash
cd site
npm install
npm run dev
```

`node scripts/check.ts` Hafta 7 hesaplarını ve soru yapısını doğrular. `main` dalına gönderilen her değişiklik GitHub Pages'e otomatik yayınlanır.
